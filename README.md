# Private EveryAyah original archive staging

Private review copies of the eight Hafs recordings currently offered by the app. No additional reciters are included. No app source, user data, credentials, or cloning tools are included. Redistribution confirmation is pending; no app migration is activated.

Each dated private release retains the original publisher ZIP. Archives larger than GitHub's per-asset limit are stored as contiguous numbered byte parts. REASSEMBLY.json records ordered parts and hashes; concatenating them yields the exact original ZIP. No MP3 transcoding, trimming, or recitation changes are made.

Each archive has all 6,236 expected numbered ayahs. SOURCE.json records archive SHA-256, every expected member hash, ZIP CRC checks, original member timestamps, HTTP Last-Modified where supplied, and publisher MD5 comparison where available. Download date is not claimed as publication date.

**Not yet eligible for app integration:** all recordings await publisher review and full integration validation. In addition, DISCREPANCIES.json records unresolved publisher-checksum differences for Minshawy 6:6 and Maher 29:63, and archive-versus-current-loose differences for Basfar 1:1 and Maher 1:1. Those original versions are retained distinctly for investigation. A successful transfer or full file count does not certify recitation correctness. Four sampled loose original files per recording were compared; this is not a complete loose-file corpus comparison or listening audit.

No original history is overwritten or automatically deleted. Original publisher: https://everyayah.com/data/ . App download routes and playback behavior remain unchanged.
