# Private EveryAyah source mirrors

Eight existing Hafs reciter collections, with original MP3 bytes retained. Private operator staging only: no public delivery and no app activation. No app source, user data, credentials, or cloning scripts are included.

**Quality:** all 49,888 expected original archive ayah MP3s passed full macOS audio decoding, with zero failures and zero warnings. All expected members are present; original ZIP CRC, recorded member hashes, and whole-archive hashes were verified. This is media/source integrity verification, not certification that a person has listened to every verse.

**Only four files are flagged for review:** Basfar 1:1 and Maher 1:1 have different original archive/current-download versions; Minshawy 6:6 and Maher 29:63 match current source bytes but disagree with the publisher MD5 entries. None failed decoding. See FILE-FLAGS.json and the detailed source comparison.

The five nondiscrepant collections use unchanged publisher ZIPs, split into contiguous byte parts where necessary. Basfar, Minshawy and Maher use clearly labelled operator transport ZIPs containing unchanged original MP3 files, with only those four individual ayahs excluded. No collection or reciter is removed. Total included audio across the eight packages: **49,884 ayah MP3s**. Original ZIPs and alternate flagged originals are retained locally; no source-driven deletion occurs.

For original ZIP parts, follow REASSEMBLY.json in the release. For operator ZIP parts, follow PACKAGE.json. Concatenate in the documented order, then verify the complete ZIP hash before extraction. These are operator transport packages; a future app routing change must expose individual eligible files without forcing full-Quran downloads for one ayah. Device use of flagged/unmirrored ayahs must retain the original source route.

Source records preserve original URLs, HTTP validators where supplied, exact hashes, archive member dates and retrieval dates. Retrieval date is not claimed as original publication date. Publisher MD5 files were unavailable for three collections and disagreed for two files; that distinction remains recorded.

Redistribution confirmation remains pending. Existing public mirrors from other cleared sources are separate. Original publisher: https://everyayah.com/data/ .
